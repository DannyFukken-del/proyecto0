
# Juego Pokémon - Versión sencilla (Python)

Descripción
-----------
Este repositorio contiene una primera versión de un juego inspirado en la saga Pokémon, implementado en Python. Es una versión sencilla y basada en texto (consola), pensada como proyecto educativo para aprender conceptos de programación: lógica de combate por turnos, manejo de datos de entidades e interacción básica por consola.

Características principales
- Combates por turnos entre dos entrenadores.
- Selección y cambio de Pokémon durante la batalla.
- Sistema básico de estadísticas (PS, ataque, defensa) y estados simples.
- Uso de ataques y objetos (pociones) desde el menú.
- Guardado y carga de partida (si está implementado en Proyecto.py).

Requisitos
- Python 3.8 o superior.
- No se requieren librerías externas para la versión de consola.

Instalación
---------
1. Clona este repositorio o descarga los archivos.
2. Abre una terminal en la carpeta del proyecto.

Uso
---
Para ejecutar el juego, en la carpeta del proyecto lanza:

```bash
python Proyecto.py
```

El juego corre en la consola. Sigue las instrucciones en pantalla para crear entrenadores, elegir Pokémon y luchar. Normalmente las opciones se seleccionan introduciendo el número correspondiente y pulsando Enter.

Estructura del proyecto
- Proyecto.py - Archivo principal con la lógica del juego (entrada, loop principal, manejo de combates).
- README.md - Este documento.

Buenas prácticas y notas
- El código está pensado para ser sencillo y didáctico; busca claridad antes que optimización.
- Si planeas ampliar el proyecto, considera separar la lógica en módulos: pokemon.py, batalla.py, entrenador.py, utils.py.
- Para añadir interfaz gráfica, puedes usar pygame u otra librería, pero no es necesario para la versión actual.
